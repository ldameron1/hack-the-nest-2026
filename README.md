# Hack the Nest 2026

Participant-authored Java combat game in the `mavenproject2` Maven project.

The current game sources are in `src/main/java/com/mycompany/mavenproject2/`.
The Maven configuration currently targets Java 23, matching the Windows NetBeans setup.

The Windows project at `C:\Users\ld\Documents\NetBeansProjects\mavenproject2`
and the WSL workspace are separate Git checkouts of this repository. Commit and
push from the checkout where you edit; pull in the other checkout before using it.
Files do not automatically synchronize between the two checkouts.

Start in `pseudocode.md`. Available event resources and links are in `docs/resources.md`.

Exa search setup and the Java adapter are documented in [docs/exa-setup.md](docs/exa-setup.md).

Repository stays private during development. The hacker packet requires a public repository for final submission; change visibility only when the owner requests it.

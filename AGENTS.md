# Collaboration preferences

- The participant chooses the idea and authors pseudocode and Java code.
- Review their reasoning and correct Java syntax or misunderstandings in small steps.
- Do not supply project ideas, solution scaffolds, or implementation unless requested.
- Keep explanations short and focused on the current step. Open relevant references when needed.
- Use Java 21, already installed. Choose a build tool only when the project needs one.
- Keep the GitHub repository private until the owner explicitly requests a visibility change.
- Never commit sponsor keys, access codes, credentials, or local datasets.
